## 만드는 방법 (개념관을 본떠서)
- 엔진: `room.js`의 `buildConcept(school, cfg)` · `updateConcept` · `stamp`가 본보기. `build()`/`enter()`에 `cfg.kind === 'concept'` 분기가 있다 → 관마다 `buildCases`·`buildDevices`… 함수와 분기 한 줄씩.
- 설정: `lobby.config.js`의 `rooms.concept`를 본떠 `rooms.<id>`(kind, 방 크기, 발판, 글). 글은 모두 `[확인 전]`/'예시' 딱지.
- 다시 쓸 것: 발판·카드(`showCard`) · 토스트 · 팝업(book/album/tv) · 회화 UI(`startPractice` — 퀴즈·상황 고르기) · `stamp(id)`(관을 끝내면 연수 수첩 도장, localStorage `xrStamps`) · `goTo`(다음 발판까지 걷기).
- 수업 사례관은 프랑스 교실 `build()`(기본 방)를 바탕으로 교과 버튼만 더하면 가장 빠르다.
- 순서 제안: cases → devices → safety → future → studio(전시 벽·메모판의 '다른 사람 것도 보임'은 서버 저장소가 필요해 마지막. 처음엔 자기 것만 localStorage로).
- 관 하나 끝날 때마다 PC 판(375×812 폰 세로 포함)에서 확인하고, 이 저장소 `CLAUDE.md`의 인수인계 절을 갱신한다.

## 지켜야 할 것
- 사실·숫자·제품명 문장은 [확인 전]. 연령 기준 같은 숫자는 넣지 않는다.
- 멀티플레이 방 이름 `xr:<관 id>`(같은 Cloudflare 서버, 하루 요청 한도를 프랑스 로비와 같이 씀). 서버 코드는 저장소 `hangul-france`의 `relay-cf/` — 이 저장소에서 서버를 고치지 않는다.
- 사진에 아이 얼굴을 넣지 않는다.
